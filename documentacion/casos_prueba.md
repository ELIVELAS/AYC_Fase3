# Casos de prueba documentados — Programas A y B

## Programa A
| Caso | Entrada (a, b, c) | Salida esperada |
|---|---|---|
| 1 | 4, 2, 3 | El resultado es: 16 |
| 2 | 10, 5, 2 | El resultado es: 28 |
| 3 | 6, 3, 4 | El resultado es: 34 |

Casos adicionales propuestos:
- 8, 4, 2 -> El resultado es: 22
- 5, 5, 1 -> El resultado es: 9
